# YouTube Shorts Auto Skipper

YouTube Shorts를 시청할 때, 영상이 끝나거나 설정한 횟수만큼 반복된 후 자동으로 다음 영상으로 넘겨주는 크롬 확장 프로그램입니다.

## 📌 주요 기능

* **자동 넘기기:** 쇼츠 영상이 루프(반복)되는 시점을 감지하여 다음 영상으로 이동합니다.
* **반복 횟수 설정:** 영상을 바로 넘길지, n회 이상 반복해서 본 후 넘길지 설정할 수 있습니다.
* **ON/OFF 스위치:** 확장 프로그램의 기능을 끄거나 켤 수 있습니다. (초기 설치 시 **OFF** 상태)
* **스마트 감지:**
    * 사용자가 직접 스크롤을 내려 영상을 변경하면 카운터가 초기화됩니다.
    * 영상을 뒤로 감기(Seek) 하는 동작을 루프로 오인하지 않도록 정교한 감지 로직이 적용되었습니다.

## 📂 파일 구조

프로젝트 폴더(`AutoShortsSkipper`)는 아래 파일들로 구성됩니다.

```text
AutoShortsSkipper/
├── manifest.json   # 확장 프로그램 설정 및 권한 정의
├── popup.html      # 팝업 UI (ON/OFF 및 횟수 설정)
├── popup.js        # 설정값 저장 및 불러오기 로직
├── content.js      # 유튜브 페이지 내 동작 제어 (핵심 로직)
└── icon.png        # 확장 프로그램 아이콘 (128x128 권장)
